## 방법론

### 벤치마킹 도구

```python
# 예제 벤치마크 스크립트
import warm_logic_rs as wl
import time

def benchmark_sign(iterations=10000):
    keypair = wl.generate_keypair()
    message = b"test message" * 100

    times = []
    for _ in range(iterations):
        start = time.perf_counter_ns()
        wl.sign(keypair, message)
        end = time.perf_counter_ns()
        times.append(end - start)

    return {
        "p50": sorted(times)[len(times)//2] / 1000,  # μs
        "p95": sorted(times)[int(len(times)*0.95)] / 1000,
        "p99": sorted(times)[int(len(times)*0.99)] / 1000,
    }
```

### 통계 방법

- **워밍업**: 1,000 반복 제외
- **반복**: 벤치마크당 10,000회
- **이상치 제거**: 없음 (실제 조건)
- **백분위수**: p50, p95, p99 보고
- **환경**: 격리됨, 백그라운드 프로세스 없음

### 재현

```bash
# 벤치마크 실행
cd rust_core
cargo bench

# Python 벤치마크
python scripts/bench/run_benchmarks.py
```

## 참고 사항 및 제한

1. **하드웨어 의존성**: CPU 아키텍처에 따라 결과가 크게 다름
2. **네트워크 조건**: 합의 벤치마크는 로컬 네트워크 가정
3. **콜드 스타트**: 시작 후 첫 작업은 10-100배 느릴 수 있음
4. **메모리 압박**: 높은 메모리 사용은 Sled 성능 저하
5. **디스크 I/O**: SSD 강력 권장; HDD는 10배 느릴 수 있음
