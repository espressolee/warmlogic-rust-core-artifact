# WarmLogic 용어집

> **목적**: WarmLogic 프로젝트 전반에서 사용되는 전문 용어를 정의하여 AI 최적화 명명법과 인간의 이해 사이의 격차를 해소합니다.

---

## 핵심 개념

### Sovereign (주권적)
**정의**: 운영 환경이 외부 통제 없이 검증 가능하고 독립적인 시스템 속성.
**맥락**: 하드웨어 신뢰 루트(Hardware Root of Trust)와 PQC 서명을 통해 강제됩니다.

### Kinetic (동적/운동학적)
**정의**: 정적 할당이 아닌, 런타임 동작이나 암호학적 증명에서 동적으로 파생되는 속성 또는 신원.
**예시**: "Kinetic Identity"는 데이터베이스 ID가 아닌, 개인키 소유 증명에서 파생됩니다.

### Era (시대)
**정의**: 주요 아키텍처 버전 체계.
- ****: 기반 (실험/연구)
- ****: 통합 (하드웨어 고정)
- ****: 현재 안정 릴리스 (현실 강제, 자기 진화)
- ****: 실험 기능 (하이브 마인드, 은하 연합)

### P-Series (단계 시리즈)
**정의**: 세분화된 마일스톤 (P001 - P999).
- **P2xx**: 완료된 기능
- **P3xx**: 활발한 개발 중

## 아키텍처

### Kernel (커널)
시스템의 고수준 Python 두뇌. 에이전트 워크플로우, 정책, SDK 상호작용을 관리합니다.

### Substrate (서브스트레이트)
저수준 Rust 기반. "보안 중요" 작업 처리: 암호화, 영속성, BFT.

### Mesh (메시)
P2P 네트워크 계층. 탐색에 Kademlia DHT, 상태 전파에 Gossip 사용.

### Ledger (원장)
모든 서명된 거버넌스 결정과 상태 전환의 불변 기록.

### Cockpit (콕핏)
개발자 제어 평면. 커널 상태 모니터링을 위한 API와 TUI 제공.

### Glass (글래스)
실시간 의사결정 추적을 위한 웹 기반 시각화 UI (대시보드).

### Hive (하이브)
쿼럼으로 작동하는 다중 주권 노드 클러스터.

## 암호화

### ML-DSA-65 (FIPS 204)
주요 서명 알고리즘 (모듈 격자 기반 디지털 서명 알고리즘). 포스트 양자 보안.

### ML-KEM (FIPS 203)
안전한 노드 간 채널 설정을 위한 키 캡슐화 메커니즘 (계획됨).

### ZK-Proof (영지식 증명)
데이터 자체를 공개하지 않고 진술이 참임을 증명하는 수학적 증명. 프라이빗 거버넌스에 사용.

### Dilithium
ML-DSA 격자 기반 서명 체계의 내부 명칭.

### MMR (Merkle Mountain Range)
원장의 효율적인 추가 전용 로깅에 사용되는 특수 Merkle 트리 구조.

### Evidence Bundle (증거 번들)
의도, 사용된 정책, 서명된 판결/증명을 포함하는 패키지.

## 합의 & 메시

### BFT (비잔틴 장애 허용)
일부 노드가 악의적이거나 실패해도 시스템이 합의에 도달할 수 있는 능력.

### Finality (최종성)
트랜잭션이나 결정이 되돌릴 수 없음이 보장되는 시점.

### SSOT (단일 진실 소스)
시스템 상태의 권위 있는 버전이 하나만 존재한다는 원칙.

### Quorum (쿼럼)
거버넌스 결정 검증에 필요한 최소 노드 수 (보통 2f+1).

### DHT (분산 해시 테이블)
키를 값에 매핑하는 분산 시스템. 메시에서 피어 탐색에 사용.

### Slashing (슬래싱)
유효하지 않은 증명 제출이나 합의 규칙 위반 노드에 대한 페널티 메커니즘.

## 거버넌스 & 정책

### Constitution (헌법)
에이전트의 근본적 제약을 정의하는 루트 정책 파일.

### GOVDEC (거버넌스 결정)
승인 또는 거부된 행동의 불변 기록.

### Veto (거부권)
다른 승인과 관계없이 행동을 차단할 수 있는 고우선순위 정책 오버라이드.

### CE (반례) / Forensic Proof
정책 위반을 증명하는 특정 시나리오나 데이터 포인트.

### τ (타우)
거버넌스 수렴 시간 상수. 합의 속도를 제어.

## 하드웨어 & 신원

### vHSM (가상 하드웨어 보안 모듈)
로컬 개발용 HSM을 에뮬레이션하는 소프트웨어 정의 보안 경계.

### SEP (Secure Enclave Processor)
WarmLogic이 앵커 키에 사용하는 Apple 하드웨어의 전용 보안 칩.

### TPM (Trusted Platform Module)
증명을 위한 Linux/Windows 머신의 표준 하드웨어 보안 칩.

### IOPlatformUUID
주권 노드를 물리적 머신에 고정하는 데 사용되는 macOS 고유 하드웨어 식별자.

### Seed Phrase (시드 구문)
주권 개인키 파생에 사용되는 24단어 니모닉.
