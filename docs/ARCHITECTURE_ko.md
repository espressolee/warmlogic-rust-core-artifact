## 1. 핵심 철학

WarmLogic은 AI 패러독스를 해결합니다: **LLM은 유연하지만 안전하지 않고, 커널은 견고하지만 안전합니다.**

### 하이브리드 유기체

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   ┌───────────────────┐       ┌───────────────────┐        │
│   │   유연한 두뇌     │       │   단단한 껍질     │        │
│   │   (Python)        │◄─────►│   (Rust)          │        │
│   │                   │ PyO3  │                   │        │
│   │   • 추론          │       │   • 암호화        │        │
│   │   • 목표          │       │   • 합의          │        │
│   │   • 자가 패치     │       │   • 원장          │        │
│   │   • 거버넌스      │       │   • ZK 증명       │        │
│   └───────────────────┘       └───────────────────┘        │
│                                                             │
│              FFI를 통해 ~300배 빠른 암호화                  │
└─────────────────────────────────────────────────────────────┘
```

| 측면 | 유연한 두뇌 (Python) | 단단한 껍질 (Rust) |
|------|---------------------|-------------------|
| **역할** | 지능 & 거버넌스 | 보안 & 영속성 |
| **가변성** | 신경가소성 (자기 수정) | 불변 (암호학적으로 봉인) |
| **신뢰 수준** | 정책 제어 | 하드웨어 앵커 |
| **성능** | 유연 | 고성능 |

## 3. 계층 아키텍처

### 3.1 애플리케이션 계층

| 컴포넌트 | 위치 | 기술 | 목적 |
|----------|------|------|------|
| **콕핏** | `app/cockpit/` | FastAPI + React | 실시간 모니터링 대시보드 |
| **CLI (wlctl)** | `app/cli/` | Typer | 운영자 명령 인터페이스 |
| **SDK** | `sdk/` | Python | 개발자 통합 API |
| **REST API** | `app/api/` | FastAPI | 외부 시스템 통합 |

### 3.2 거버넌스 커널

| 컴포넌트 | 위치 | 목적 |
|----------|------|------|
| **헌법** | `kernel/constitution.py` | 의미론적 불변식 (우회 불가) |
| **정책 엔진** | `kernel/policy_engine.py` | 동적 규칙 평가 |
| **Zanzibar RBAC** | `kernel/zanzibar.py` | 관계 기반 접근 제어 |

### 3.3 암호 기반 계층 (Rust)

| 컴포넌트 | 파일 | 기술 | 목적 |
|----------|------|------|------|
| **서명** | `crypto.rs` | ML-DSA-65 (FIPS 204) | 포스트 양자 서명 |
| **합의** | `consensus.rs` | WL-BFT-v1 | 비잔틴 장애 허용 |
| **ZK 증명** | `proof_zk.rs` | 시그마 프로토콜 | 프라이버시 보존 규정 준수 |

## 6. 컴포넌트 상세

### 6.1 SDK (SovereignClient)

```python
from warm_logic.sdk import SovereignClient

client = SovereignClient(host="localhost", port=8000)

# 액션 제안
decision = client.propose_action(
    intent="send_email",
    context={"to": "user@example.com"}
)

# 결과 확인
if decision.approved:
    bundle = client.get_evidence(decision.proof_hash)
```
