# Troubleshooting Guide

> **Quick Fix**: If something is broken during development, try running `make clean && make build`.

## 1. Installation & Build Issues

### `maturin: command not found`
**Cause**: The build tool `maturin` is not installed or not in your PATH.
**Fix**:
```bash
pip install maturin
```

### `error[E0463]: can't find crate for 'std'`
**Cause**: Rust toolchain is missing or corrupted.
**Fix**:
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env
rustup update
```

### `ImportError: No module named 'warm_logic_rs'`
**Cause**: The Rust core has not been compiled or linked correctly.
**Fix**:
```bash
# Developer install (compiles Rust and links it)
make install-dev
```

## 2. Docker Issues

### `Bind for 0.0.0.0:8000 failed: port is already allocated`
**Cause**: Another process is using port 8000.
**Fix**:
1. Find the process: `lsof -i :8000`
2. Kill it: `kill -9 <PID>`
3. Or modify `docker-compose.yml` to map to a different port (e.g., `"8080:8000"`).

### `dial tcp 127.0.0.1:6379: connect: connection refused`
**Cause**: The `audit-spine` (Redis) is not running or not reachable.
**Fix**:
Ensure you are running the full stack:
```bash
docker-compose up -d
```

## 3. Runtime & Logic Issues

### "SYSTEM_HALT: Attestation Failed"
**Reason**: The kernel detected that you are running on unverifiable hardware (or a simulator) without the proper flags.
**Solution**:
- **For Development**: Set `WARM_DEV_MODE=1` in your `.env` file.
- **For Production**: Set `WARM_SOVEREIGN_SEAL` to the signature generated by your HSM/TPM.

### "CRITICAL: Rust Core missing"
**Reason**: Python cannot import `warm_logic_rs`.
**Solution**: Re-run `maturin develop`.

## 4. Health Checks

### Check UI Server
```bash
curl http://localhost:8000/health
# Expected: {"status": "ok", "kernel": "active"}
```

### Check Logs
```bash
docker-compose logs -f warmlogic
```
